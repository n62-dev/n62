### gorge, X20: a backup's definitions and chips pass the library's check before they are stored, branch `p1/gorge-backupcheck`
**Lane:** B, night-safe, Opus (stored Giac text). **Starts when:** –. First two weeks.
**Why:** (arch review 2026-11-10, B4) Two doors bring Giac text into the app, with different locks. A library file is read by Giac's parse tree and refused when it holds a state-changing or string-evaluating command (`app/src/engine/stores.ts:21-34`, `app/src/engine/library.ts:140-190`). A backup file's `defs` are checked for shape only (`app/src/state/backup.ts:221`, `app/src/engine/defs.ts:103-131`), and their commands are replayed as Giac text at every start; a chip's value goes to Giac in brackets unless it holds `;` or `:=` (`app/src/input/chip-giac.ts:32-46`), and chips come from the backup's history and user keys (`app/src/input/chips.ts:66-86`). The replay has no time limit of its own (`app/src/engine/workerEngine.ts:138`; the watchdog arms only for Home and unit calls, `:370`). Giac in wasm reaches no file and no network, so the harm is bounded: a crafted or damaged file can purge or redefine the user's names, or hang each start until two kills lead to the safe start.
