6. **The words.** The release notes: what is in, the known limits (point 3's marked lines; what of Structure has not merged), the engine and qalc hashes (A8); the README and the fastlane screenshots match the build; the README's "Why trust it" section (A93), its numbers read from the files and checked at the tag (`npm run trust:check`); `changelogs/1.txt` (A91); About (R87) names the version.
7. **What v0.1.0 keeps for good, checked once by hand on the release candidate.**
   - **Identity:** the application id `dev.n62.calc` and the signing certificate (`android/release-cert.sha256`); the WebView's origin (`https://localhost`: `app/capacitor.config.ts` has no `server` block, and never gets one) and the web origin `https://n62.dev` (the store belongs to the origin); `sw.js`'s path and scope; the manifest `id`; the release asset's name `n62-X.Y.Z.apk`.
   - **The store:** IndexedDB `n62`, store `kv`, the stamp `{"@n62": n, value}`, the keys of `BACKUP_KEYS` and `LEFT_OUT` (`app/src/state/backup.ts`), `DATA_VERSION` as tagged.
   - **The two files the app reads back:** the backup (`"n62-backup": 1`) and the library (`// n62 library <n>`).
   - **The names stored inside them:** the Find token ids (`unit:`, `pfx:`, `const:`; the ids `find/units.yaml` `rename:` gives libqalculate's US units and the hand-written ones included, G321) and the prefix of a user's own unit; the key ids a record names (the user keys, the unit pad cells, the layers `primary`, `shift`, `alpha`) and the action words (`type`, `insert`, `cmd`, `special` and the specials' names); the settings' values and the look families; the stand-in names (`e_`, `i_` and the Greek ones of `app/src/engine/standIns.ts`); the prefix `pas`, which is ours (G341).
   - **The rule:** after the tag none of these changes without a `DATA_VERSION` step, and a new stored field, value or key raises `DATA_VERSION`. `app/src/state/fixtures/backup-0.1.0.json` (R292 makes it: every part filled, made by the release candidate) restores in every later build.
   - **Not kept:** the session lines (`"v":0`), the `.py`, `.csv`, `.tex` and report files, the counts file, the text "format for your AI". Where the format has room, the file says so (the `v` field; a first-line comment in the `.py`, `.tex` and report files); the release notes and the Sync folder page say it for all of them.
   - **By hand:** save a backup on the release candidate, restore it on the other device and on the web; export a library and import it; read the first line of each export file.
