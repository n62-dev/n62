**The rule:** left operand: one factor (`3+4∡30` is `3+(4∡30)`). Right operand: one signed factor (a power counts, `30^2`; a `\frac` counts). `10∡30*2` is `(10∡30)*2`. In a flat line a bare `/` right after the angle or right before the radius is refused with "put the angle in brackets" (Giac would read `2∡π/6` as `(2∡π)/6` = -1/3, silently not what is meant); a factor written directly after the angle (`10∡2π`, `10∡2x`) is refused the same way, since it would otherwise multiply `(10∡2)·π` silently. A stacked `\frac` stays fine (`2∡\frac{π}{6}`).
