**Why:**
- **The map (T5, [ui-analysis.md](../../research/t5-ui/ui-analysis.md) problem 1, [checks.md](../../research/t5-ui/checks.md) "Back does not return"):** on the phone and the tablet, Back after
  - the digits chip,
  - Shift + ☰ (or a flick up on ☰),
  - a ☰ menu's ⚙,
  - or a user key that holds Settings

  lands on the Mode sheet, a level the user never opened. A second Back reaches the place they came from.

- **The rule broken:** Android's Back, and the walk's check, expect a return to where the user came from. docs/05 3.4 says "Android back goes back one level". That is true here, but the level below was never seen.
