### gorge, G555: a list or matrix divided by a matrix is refused with the forms that mean something, never Giac's pointwise `=`, branch `p1/gorge-matdiv`
**Lane:** B, night-safe, Opus (a wrong matrix with `=`; a refusal pinned by tests). **Starts when:** –. The owner's answer (2026-11-16): refuse, as recommended; (b) below is dropped. Before the freeze if lane B has room; else a fix row before the tag.
**Why:** (T2 bug hunt 2026-11-16, F306; `../drafts/2026-11-16-ultra/t2-bughunt/hunt-stats.md`, engine `_out/gsl`, phase-1 `e93dec77`.)
- **What happens:** `A:=[[1,2],[3,4]]`. Then in Home (÷ or the fraction template; both send `A/B`):
  - `identity(2)/A` shows `[[1,0],[0,0.25]]` with `=`; A⁻¹ is [[−2,1],[1.5,−0.5]].
  - `A/A` shows `[[1,1],[1,1]]` with `=`.
  - `B:=[[2,0],[0,4]]`, `A/B` shows `[[1/2,infinity],[infinity,1]]`, though B is invertible.
- **A size mismatch drops elements:** `C:=[1,2,3]`. `A/C` shows `[[1,2],[1.5,2]]` with `=`, and C's third element is dropped without a word. `C/A` gives `[1/[1,2],2/[3,4]]`.
- **Cause:**
  - Giac's `rdiv` of two vectors (`gen.cc` about 8430-8441) divides element by element. It logs "Warning, pointwise division … please use inv(b)*a or a*inv(b)", which never reaches the user. `apply(a,b,rdiv)` pairs the elements and drops the extra ones.
  - N62's matrix walk (`app/src/engine/nonsquare.ts:240-241`) checks `/` only for a non-square denominator, and `COMBINING` (`nonsquare.ts:43`) holds `./` but not `/`.
  - A number over a matrix is already a·M⁻¹ (`2/[[1,2],[3,4]]` = [[−4,2],[3,−1]], the `nonsquare.ts` header).
- **Why a refusal (recommended):** A·B⁻¹ and B⁻¹·A differ, and engineers mean both, so a refusal that names both forms is the one reading that is never wrong. The pointwise meaning stays reachable as `./` (G352). Owner's choice; the other answer is (b) below.
