**Why:** (arch review 2026-11-10, pattern 6, draft X27; rechecked at `5a583f31`)
- **Two engines.** Development and the gate's sweep stages run the engine built with emsdk 6.0.12 (`engine/giac/build-wasm.sh`); the APK and the site carry the one built with Debian trixie's Emscripten `3.1.69+dfsg-3` (`engine/giac/build-wasm-release.sh:24`). Two compilers and two C libraries can differ in a double's last bits, and a double's last bits are what the mark decides on.
- **The release gate runs four stages on the shipped engine:** build, golden, canaries, core (`tools/release-gate.sh:29-32`, `:55-57`). The five stages that find false marks never run on it: `sweep`, `seqsweep`, `casback`, `viewsweep`, `findcensus` (`app/scripts/gate.ts:183-245`, each with `GIAC_OUT: engine`).
- **A comparer exists:** `app/scripts/compare-engines.ts` prints every golden input whose output differs between two builds; it does not cover the sweeps' generated inputs.
