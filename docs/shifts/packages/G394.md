**Lane:** either, Opus (stored data, kept for good from now on). **Starts when:** G393 merged; after the v0.1.0 tag (0.2), before R356.

**Why:**
- **The pairs must be kept** ([the design note](../../research/name-rules.md) section 4): a ΔT in history must still draw as ΔT and read as `DeltaT` after a relaunch, a backup or a Sync.
- **Release point 7** (`docs/release-0.1.0.md:13-19`): a new key means a `DATA_VERSION` step and a `BACKUP_KEYS` part with a validator. R292's fixture must still restore.
- **Old data must keep its meaning.** A name a v0.1.0 row reads may be stored, or deleted since and still read by a recalled row. That name must keep its engine name and never be given to a new display. So the step seeds the registry instead of leaving it empty.
- **T1 (sofia, re-check 3):** Giac's own names read as values when they are not stored: `PI` is π, `DIGITS` is 12, `epsilon` is 1e-12, `inf` is ∞, `MAX` is undef, `mean` is `'mean'` (smoke).

  - **Why another check is needed:** `refuseStore` lists only our tables (`app/src/input/parseTables.ts:59-66`), and G354 catches a store, not a read.
