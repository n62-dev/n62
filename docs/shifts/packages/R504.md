**Why:**

An engineer defines `p(q):=…` (a pump curve) or `f(x):=a·x²` in Home and wants to see it; today F1 = `f(x)` draws nothing: `compileDefinition` (`app/src/apps/function/compile.ts:27-44`) throws in `jsonToJs` on the name f (`app/src/input/emit-js.ts:31-34`, `parse.unknownName`). - **What makes it drawable:** G507 keeps the defining LaTeX (`src`) on the function's log entry. Our parser turns it into the same tree the Plot already compiles; the call `f(expr)` is drawn as the body with its parameter replaced by `expr`. Names inside the body are resolved as R361 resolves the slot's own (stored real values), and other user functions recursively.
- **Exact meaning:** Home evaluates `f(2)` with Giac in the current angle mode; the Plot draws in the app's angle mode (`compile.ts`'s `angle`), so a body with `sin` is drawn in the same mode Home would use for the slot.
