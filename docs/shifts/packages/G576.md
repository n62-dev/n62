**Cause:** Home sets Giac's power limit to `powLimit` (`app/src/engine/homeEval.ts:59-62`, applied by `host.ts:1313`), so an exact power past it fails "at once" (a rational base counts its numerator: `(100001/100000)^100000` is n·ln 100001 ≈ 1.15E6, past 1E5, though its value is 2.72) and goes to the float path (`homeEval.ts:655`, `viaFloat("float-error")`). The float path (`homeEval.ts:602`, `floatPathFacts`) evaluates the same text under the same limit, so it fails the same way. Raw Giac without the limit gives `evalf(2^1000000)` = 0.990065622930e301030 (smoke.mjs); with a float exponent at double precision it is `infinity`, so the float path needs the limit lifted (or the exponent at P digits), not a double.
