**The result: rule 3.** At a box's start, in an empty box (□ selected) or at a gap (lim's, ∫'s, evaluate-at's: the start of the box after it):
- a **bare** node goes and its main content stays (□ where it filled a box); any other node is **selected**, the next ⌫ deletes it. No exception, the fraction included.
- *Bare:* no extra box holds a value (a box holds one unless it holds only □ or one lone sign − + ±); a power's base counts the power's script as an extra box.
- A box with no left edge (base, whole part, degrees) has no start: the position before it is the line's. Del mirrors at a box's end.
- `main` and `arg` become one role (numerator, whole part, degrees, ⁿ√'s radicand, EQ's and par's a, a pair's body).
