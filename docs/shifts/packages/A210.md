### annabell, A210: the strength slider works on a motor without amplitude control (a scaled tick), branch `p1/annabell-tickstrength`
**Lane:** by day (a device: the Fairphone 6, free from Wed 11-18 after A61), Sonnet. **Starts when:** after the v0.1.0 tag; the Fairphone free (the owner's day plan names it). Owner, 2026-11-02: "a package later" (backlog "A9's leftover").

**Why:**
- **A9's report** (`8c1e5f06`): the Fairphone 6 (Android 16, API 36) motor has no `AMPLITUDE_CONTROL`, only primitives (CLICK, TICK, LOW_TICK, THUD). The plugin plays `createOneShot(ms, ctl ? amp : DEFAULT_AMPLITUDE)` (`android/app/src/main/java/dev/n62/calc/N62HapticsPlugin.java:110-112`), so on that phone the slider sends an amplitude the motor ignores: every strength feels the same.
- **The slider still looks live there:** `hasStrength()` is true for any native build (`app/src/input/haptics.ts:29-31`), and the Mode sheet greys the row only when it is false (`app/src/views/modeSheet.ts:166`). A9's report says so: "hasStrength() says true for any native build, and the slider does nothing on the FP6".
- **A9's proposed cure:** "a composition of PRIMITIVE_TICK at the slider's scale". `VibrationEffect.startComposition().addPrimitive(PRIMITIVE_TICK, scale)` takes a scale of 0..1 (API 30+), and `Vibrator.areAllPrimitivesSupported` tells whether the motor plays it.

2. **The change:**
   - **The plugin:**
     - `caps()` returns `{ amplitude: hasAmplitudeControl(), primitives: areAllPrimitivesSupported(PRIMITIVE_TICK) }` (false below API 30);
     - `vibrate` uses a one-shot with amplitude where the motor has amplitude control (unchanged);
     - otherwise, where TICK is supported, it plays a composition of one `PRIMITIVE_TICK` at `amplitude / 255`, with USAGE_PHYSICAL_EMULATION on API 33+ as today;
     - otherwise it uses the plain one-shot.
     - The length (`ms`) has no meaning for a primitive: the Mode sheet's length row is disabled when the plugin says so (a second flag, `lengthApplies`), with the reason in the row's hint.
   - **`haptics.ts`:** `hasStrength()` reads `caps()` once after `loadNative()`.
   - **i18n:** the hint for the disabled length row.
