### ron, R838: Settings and Mode open over the unit view and close back onto it, branch `p1/ron-unitsettings`
**Lane:** v0.1.1, Sonnet. **The owner's yes:** 2026-11-20 night, his U2 (sandra's recommendation 7 in `../drafts/2026-11-20-owner-bugs2/DECISIONS.md`, outside the repo). **Starts when:** after R770 (every window in the viewport). **Lock:** none (no key, layer or list changes: the same keys open the same sheets; only what happens to the view behind them).

**Why:**
- Today Settings (Shift + Help, a user key that holds it) and Mode (the STD and 12 chips, a user key, Alt + Shift + O) close the unit view first: `app/src/units/open.ts:68` lists `settings` and `mode` in `PLACES`, "keys that change place", and `unitPad.other` (`:219-224`) calls `close()` for them. The slots the user built are gone (`../drafts/2026-11-20-owner-bugs2/U/u2-settings-open.png`, `u2-after-esc.png`).
- They are not places: since R770 every sheet opens in the viewport with the keys live, and a sheet takes the keys while open (`units/pad.ts:153`, `if (c.shell.sheet) return false`). What the unit view does with keys under a sheet (`unitPad.other` and `unitPad.on`) is untested.

**The result:**
- In the unit view, Settings and Mode open as sheets over it, from every route (Shift + Help, the chips if the bar shows them in the unit view, a user key, Alt + Shift + O, the ⚙ in a ☰ title row). The view stays as it was: slots, the active slot, its caret (R806 to R808 if merged), an armed prefix, the result.
- While the sheet is open, every key goes to the sheet (digits pick rows, ▲ ▼ move, Enter picks, Esc and Back go back one level); no key reaches the unit pad or the view.
- Esc, Back, × or a pick that closes the sheet land on the unit view with the focus on it (the hardware keys work at once, `open.ts` `keep`).
- A setting changed there that the view shows (digits, format, the decimal mark, σ display, digit groups, the look) redraws the view's result on close, with no new engine call when only the drawing changed; an angle change recomputes as the line would.
- Home, CAS, Apps, Symb, Plot, Num and switch stay places: they close the view as now.

**Read:** `app/src/units/open.ts:60-75,200-260`, `app/src/units/pad.ts:150-165`, `app/src/keyboard/route.ts` (where Settings and Mode open; `special settings`, `special mode`), `app/src/apps/shell.svelte.ts` (`sheet`), `app/src/views/sheet.svelte.ts` (close), `app/src/units/view.ts` (redraw), `app/test/unitback.spec.ts`, `unitresult.spec.ts`, `unitpad.spec.ts`, `sheet.spec.ts`.
