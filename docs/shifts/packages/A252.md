### annabell, A252: a pre-push hook refuses a push that adds over 5 MB or a binary outside the allow-list, branch `p1/annabell-prepush`
**Lane:** the fix lane after A251, Sonnet; no device. **Starts when:** A250 merged. After the merge the coordinator runs `tools/hooks/install.sh` in every clone that pushes (this machine's main checkout, lin99's checkout) and lists them in `tools/README.md`.

**Why:** the 28 MB `p1/t5-ui` of 2026-11-16 reached GitHub by a hand push from lin99, so neither the pipeline guard nor a hook on one machine alone would have stopped it; the owner: no bloat "under no circumstance". Why 5 MB: a push carries days of merges (the busiest week added 5.2 MB, this one 1.9 MB).

**Read:** `tools/repo-weight.sh` and `tools/weight-allow.txt` (A250), `tools/README.md`; hooks live in `$(git rev-parse --git-common-dir)/hooks` (a worktree's `.git` is a file).

1. **Tests first** (`tools/hooks/pre-push.test.sh`, pure bash, in the gate), on a scratch repo with a local bare remote:
   - a push adding a 6 MB file is refused: `WEIGHT … over origin: refused (N62_WEIGHT_OK="<reason>" to override)`;
   - the same with `N62_WEIGHT_OK=test` passes and prints the reason;
   - a branch delete passes; a 200 kB text branch passes;
   - with `repo-weight.sh` failing (exit 2) the push is refused, never passed.
2. **The change:** `tools/hooks/pre-push` reads the pushed refs from stdin and measures each new tip with `tools/repo-weight.sh --limit 5000000 <tip> --remotes=<remote>` (A250 expands it); refuses as above. `tools/hooks/install.sh` links it into the common hooks dir (idempotent; refuses to overwrite a different hook).
3. **Docs:** `tools/README.md` (the hook, the override, install, the clones it is installed in).

**Done when:** the test passes in the gate; after the merge the coordinator installs it and a push of phase-1 to a local bare mirror passes.
