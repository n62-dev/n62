### ron, R847: Find for a user-key slot names the slot ("U1 ⇧"), offers a Places category, and Back returns to where it was opened, branch `p1/ron-slotfind`
**Lane:** v0.1.1, Sonnet. **The owner's yes:** 2026-11-20 night, his Y1 (the user-key setup; part 1 of 3: R847, R848, R849). **Starts when:** after R821 (`layers()`, the slot rows). **Lock:** none (user keys and the Your keys level are not pinned; `spec/layout-lock.yaml` pins only Settings' row 4).

**Why** (sandra's probe, `../drafts/2026-11-20-owner-bugs2/Y/FINDINGS.md`, `y1probe*.spec.ts`, outside the repo):
- Find for a slot is titled only "Your key" (`i18n/enFind.ts:44`, shot `y1-4-find.png`): nothing says which key or layer it fills.
- It opens with no parent: `shell.picked` sets `this.sheet = null` before the item's `run` (`apps/shell.svelte.ts:299-303`), and `chooseFor` → `openFind(slot)` (`App.svelte:220,259`) → `shell.showFind` (`shell.svelte.ts:263`) opens a new sheet at depth 1, so ‹ is not drawn (`views/Sheet.svelte:207` needs depth > 1) and Esc, ◀ or × close to the keypad (`route.ts:322-327`). One wrong slot means the whole chain again.
- Find has no place items (its index kinds are fn, tmpl, const, unit, pfx): the slot level's PLACES (`views/yourKeys.ts:32-39`: Home, CAS, Apps, Menu, Mode, Settings) are the only way to put a place on a key; a Find-only slot (AFTER-TAG A3) would lose them, and docs/06 :19 relies on "Mode: a user key".

**The result:**
- **The title** names the slot: "U1" for the tap, "U1 ⇧" for Shift, "U1 α" for Alpha (only while R821's switch is on); the key's id and the layer's sign come from `labelOf`'s neighbours in `userKeys.svelte.ts`, the string from i18n.
- **A Places category** at the end of Find's category rows, only when Find is opened for a slot: Home, CAS, Apps, Menu, Mode, Settings (the same `Special`s as `PLACES`, the same labels); a pick sets the slot to that place. Letters typed in Find also match these names.
- **Back:** Find opened for a slot carries a `parent` (the sheet it was opened from: the Your keys level today, R848's key sheet later); ‹ is drawn, and ‹, ◀ at Find's top level, Back and Esc return to the parent with its highlight where it was. × closes all. **A pick closes all and lands on the keypad** (the key shows its new legend at once: R821's refit).
- Settings › Your keys › a slot opens this Find directly. Its 8-row level goes (the owner's AFTER-TAG A3 of 2026-11-19, `../drafts/2026-11-19-owner-bugs/AFTER-TAG.md`: "only search + Empty"; Vars names in Find are not part of this package): the places are inside Find, and "Empty this slot" becomes an option button on the slot's row (the Sheet's `options`, as Mode uses them, `apps/types.ts:79`).
