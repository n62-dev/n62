### gorge, G509: the arch review's hunt becomes golden rows, part 1: the converter and the Home tasks, branch `p1/gorge-hunthome`
**Lane:** B, night-safe, Sonnet (test data and a converter; no engine change). **Starts when:** after the v0.1.0 tag (0.2). Before G533 and G534, which reuse the converter.

**Why:**
- **The arch review placed it** (`docs/research/arch-review-2026-11-10.md`, section 5): "The hunt's 660 tasks (`hunt-tasks.yaml`, 584 passing, 35 marked `duplicate_of`) become golden rows in a gorge package, with the gate's time checked." The file is in git: `docs/archive/arch-review-2026-11-10/hunt-tasks.yaml` (678 lines; fields in its head comment, named as `tests/golden/*.yaml` names them).
- **What is in it** (counted by kind and result on `5a583f31`): Home tasks (no `kind`) 162: 134 pass, 15 pass duplicates, 8 finds, 3 "as designed", 1 refused, 1 observed; HUNT-2's `raw, home and cas` 277 (G533); CAS 94, units 70, Solve 31, the Function views 21, paste 2 (G534).
- **Already imported:** 12 `hunt-*` rows in `tests/golden/home.yaml` and 22 in `precision.yaml` (G322 and the night reviews), so the converter must skip an id or input/settings pair a golden file already holds.
- Today these tasks are run by nobody: a regression on any of the 134 passing Home tasks (everyday electrical, settings, reuse through chips, weak paths, σ) goes unseen.
