### ron, R740: Store ▶ on a folded pick keeps the keys down; the store sheet's "New name…" row brings them up, branch `p1/ron-foldstore`
**Lane:** the freeze's fix lane, night-safe, Sonnet. **The owner's yes:** 2026-11-17 ("the keypad should stay folded"), before the tag. **Starts when:** –; the first of the layout and history rows in the fix lane (owner, 2026-11-17), before R722 and R724 (R724's folded bar already says Store ▶ keeps the keys down).

**Why:**
- Folded, a row picked, the bar's Store ▶ opens "Store in" and unfolds the keypad. The sheet then covers the history, so the row being stored is out of sight (seen at 412 × 815 on phase-1 228bc43f, `tools/probes/history-1117/probe-folded.mjs`; T5's map, folded root p345 › ☰ 4 → p356 without `[folded]`).
- **Cause:** `storeRow` (`app/src/clipboard/actions.svelte.ts:364-372`) puts the chip on the line with `this.ops.insert(i, true)`. That is App's `insertResult` (`App.svelte:47`), which runs `onLine` (`:396-402`), and `onLine` always sets `folded = false` (`:398`). Store inherits the rule "an insert brings the keys back", which was written for the second tap.
- The keys are not needed: a tap on a letter A–Z or a stored name stores (`views/storeSheet.svelte.ts`), and a letters sheet keeps the line in view above the bar, folded or not (`App.svelte:543-546`). Only a longer new name needs letters, and a hardware keyboard types folded already (`fold.spec.ts:236-239`).

**The result:**
- Folded, Store ▶ (the bar's, ☰'s Store ▶, Shift + ᴇ by a hardware key on a pick) puts `value ▶` on the line and opens "Store in"; the keys stay down.
- A tap on a free letter or a stored name stores, as now; the keys stay down, and the new row shows in the history.
- While folded, the sheet's last row is **New name…** (`id: "new"`, `keep: true`): it brings the keys up and the sheet stays open with the filter ready, so Alpha and the letter keys type the name. Unfolded, the row is not drawn (the keys are there).
- Esc closes the sheet and leaves `value ▶` on the line, as unfolded; a second Esc unfolds (route.ts `escape`).
- Counted while folded: `store` as now, and `store.new` for New name… (`state/uses.svelte.ts`), so P16's review sees how often a folded store needs the keys.
