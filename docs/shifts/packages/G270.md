**The rules:**
1. σ at full precision to 2 significant digits, nearest, half away from zero (`twoDigits`). The value is rounded to σ's last place (`roundTo`).
2. The bracket is that 2-digit integer, referred to the last digits of the value. It stands for the standard uncertainty (σ), never for U.
3. The value is written as `write` writes it: plain for `e10` from −4 to below 12, else mantissa and exponent. The exponent goes after the bracket (`6.67430(15)E-11`). Where σ's last place is above the units digit the exponent form is forced, with the mantissa ending at that place (`1.235(12)E4`, never `12350(12)`). A value that rounds to 0 follows the same limits read on σ's own exponent (`0.000(50)`, `0(12)E1`, `0(10)E-41`).
4. No form (null) for σ 0, for text that is not a plain decimal, and when `e10 − place + 1` exceeds `maxDigits` (`e10` the value's exponent, `place` σ's last place): the digits are not known that far. `maxDigits` is the digits evaluated (30), or Home's `reliableDigits` where the caller has it. A value of 0 is not refused.
