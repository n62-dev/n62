### ron, R358: letters typed under Alpha lock are one name, branch `p1/ron-alphaword`
**Lane:** A, Opus (keys and MathLive editing); the owner tries it on the phone after the merge. **Starts when:** R356 merged; after the v0.1.0 tag (0.2), before R346. **The owner's answer (2026-11-16):** one name everywhere, CAS too.

**Why:**
- **The rule:** the owner's rule of 2026-11-16 ([the design note](../../research/name-rules.md)) names the Alpha-lock word as one way to enter a name.
- **Today there is no word:** each letter is typed alone (`app/src/keyboard/route.ts:494` `entry.run({ kind: "type" })`; Alpha lock is `alphaLock`, `app/src/state/session.svelte.ts:235`, `:379-392`).
  - So Alpha-lock R A T E is `R*A*T*E`, and a name of more than one letter needs the Store sheet or Vars.
- **Under the rule:** a run of letters typed under one Alpha lock is entered as a name, `\operatorname{RATE}`. Letters typed apart stay a product, drawn with R354 and R355's dot.
