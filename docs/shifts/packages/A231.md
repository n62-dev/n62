**Why:** (t3-research 2026-11-16, `desktop.md`) the sync folder (A65, A100, A101, A137) exists only on Android. `app/src/clipboard/folder.ts:53-61`'s `plugin()` returns the Capacitor plugin `N62Files` or nothing, and "on the web … every call answers unavailable" (`:2-5`). An engineer who calculates on the phone and at the desk is the case the folder is for. On the desktop, the installed web app is the recommended product. Chromium's File System Access API gives a page a folder the user picks: `showDirectoryPicker`, a handle kept in IndexedDB, and `createWritable`, which writes to a swap file and puts it in place on `close()`. Safari and Firefox have no `showDirectoryPicker`; they keep "unavailable", as today.
