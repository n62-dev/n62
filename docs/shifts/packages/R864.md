**Why:**
- R142 sets a legend in the variable face exactly when its key types one letter (`app/src/keyboard/variable.ts:2-11`; CSS `Keypad.svelte:513-526`).
- A template's letter stands for "your number", which is a variable, but the template types no letter, so the flag never sees it.
- The x key draws an italic *x* (its Shift legend an italic *y*), and the keys around it draw the same letter upright. Sandra's probe (`../drafts/2026-11-22-owner-bugs3/s2-probe-legends.spec.ts`, screenshot `s2-360-main-dark.png`) and sofia's check (`verify.md`, S2 point 16).
- The labels: `spec/keyboard.yaml:164` (`xʸ`, `ⁿ√`), `:203` (`eˣ`), `:212` (`10ˣ`), `:223` (`x²`), `:238` (`|x|`), `:302` (`x⁻¹`). On the unit pad, `units/pad.ts:60-68` (`x⁻¹`, `x²`, `√x`, `x³`, `x⁴`; R803: "drawn as on the main keypad").
- Not `a b/c` (`:149`): it is a mixed-number pattern, not one placeholder (owner).
- R729 K4 puts `a` (top left) and `A` (bottom left) on the Alpha key. Their action is the Alpha modifier, so `typesVariable` is false and they would be upright beside the italic *A* on Vars. They show letters that layer types, so they get the variable face.
