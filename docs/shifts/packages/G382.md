### gorge, G382: a decimal inside a string is never rounded, branch `p1/gorge-stringdigits`
**Lane:** B, night-safe, Sonnet (the Home number formatter, one scanner swap, pinned by tests). **Starts when:** –. A fix; before the freeze (owner, 2026-11-15: Monday's small packages); last of them, as its reach is low.
**Why:** (backlog F206, G172's report; id: Opus pass 122) When a result that is not a number also holds a real float, `floatsAtDigits` (`app/src/engine/numeric.ts:95`) rounds every float literal in Giac's print to the display digits with its own regular expression, the digits inside a string too: `list[x,"0.1234567890123456789",evalf(1/3)]` shows the string as `"0.123456789012"`, in Home and CAS. `hasFloat` (`:85-87`, G172) already skips strings, and `mapNumbers` (`app/src/engine/giacPrint.ts:492`) maps number literals outside strings and names; `floatsAtDigits` uses neither. A string is text: what the user typed in it must come back as typed. Family 1.
**Stored data:** this package adds no stored field or value and renames no stand-in (release-0.1.0.md point 7).
**Read:** line numbers as of `081709de`; recheck at start. `app/src/engine/numeric.ts:70-130` (`hasFloat`, `floatsAtDigits` and its callers, `matrixRead.ts:145`); `app/src/engine/giacPrint.ts:480-520` (`mapNumbers`, `Quoting`); backlog F206.
1. **Tests first, failing on phase-1** (unit tests beside the numeric tests, real engine where it needs one; one golden `home.yaml` case, `source: derived`): `list[x,"0.1234567890123456789",evalf(1/3)]` keeps the string's 19 digits and shows the float at the display digits; a string with an exponent (`"1.5e300"`) and one with an escaped quote before its digits keep theirs. The same in CAS. Controls (pass today and after): a float outside any string rounds as today (G38: `piecewise(sin(10^50)>0,x,evalf(1/2)*x)` stays 0.5*x); a name with digits (`x1`) and a hex literal are untouched; a string alone.
2. **The change:** `floatsAtDigits` rounds only the literals outside strings, through `mapNumbers` (or its string rule), with its rounding unchanged; nothing else in the formatter changes.
