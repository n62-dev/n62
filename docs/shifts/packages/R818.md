### ron, R818: Vars and Memory rows say what a name holds: list, matrix, complex, function or unit, branch `p1/ron-namekinds`
**Lane:** v0.1.1, after the tag, Sonnet (the owner, 2026-11-20 evening, his walk point C7, the first of two: R819 adds the filter chips). **Starts when:** –. No lock change. Vars stays flat: no G2 categories (decided); Memory shows no memory sizes (the owner).

**Why:**
- A stored name knows only `kind: "var" | "fn"` (`app/src/engine/defs.ts:150-160`, `UserName`); its preview is text (`{1,2}`, `[[1,2],[3,4]]`, `3+4i`, `12 m/s`), so a list, a matrix and a number look alike until read.
- The engine knows the shape when the value is stored (the result's kind; a value with a unit comes from the unit view's store, R353, or a Home result that read one, G392), so the tag is recorded there, not guessed from the text.

**The result:**
- Each name's row in Vars and Memory, and the line under Vars' grid for a cell, carries a short muted tag: list, matrix, complex, function or unit; a plain real number has none. Tags are words from the i18n table, in the row's value colour, never a colour of their own.
- A name stored before this package (an old log) gets its tag from its preview's form (`{` list, `[[` matrix, an `i` part complex), or none.

**Read:** `app/src/engine/defs.ts` (`DefEntry`, `userNamesOf`), where a store writes its entry (`grep -n "kind: \"var\"" app/src/engine/*.ts`), `app/src/find/names.svelte.ts` (`nameRow`, `previewOf`), `app/src/views/storeSheet.svelte.ts` (`filled`).
