### ron, R356: the parser reads every name token through the registry; Giac's own names are refused, branch `p1/ron-nametoken`
**Lane:** A, night-safe, Opus (the parser). **Starts when:** G394 merged; after the v0.1.0 tag (0.2), before R357, R358 and R346.

**Why:**
- **The rule** ([the design note](../../research/name-rules.md)): a defined name is one token. It is entered as `\operatorname{…}` (Store sheet, Vars, Alpha-lock word) or as a letter with a subscript (`T_{1}`, and now `\omega_{n}`). It is read through G393's registry.
- **The parser today:**
  - reads `\operatorname{X}` only when X is stored, and refuses it otherwise (`app/src/input/parse.ts:775`, `:795`; R258);
  - joins a group's tokens, so `\operatorname{\sigma max}` and a typed "sigmamax" are one name (`groupText`, `:418-428`);
  - refuses a Greek letter with a subscript (`\omega_{n}`: "unexpected token", probe);
  - takes no subscript after `\operatorname{…}`.
- **T1 (sofia, re-check 3):** a free name token would read Giac's own names: `PI` is π, `DIGITS` is 12, `epsilon` is 1e-12, `inf` is ∞, `MAX` is undef, `mean` is `'mean'` (smoke). G394's registry refuses those displays. This package makes the parser go through it.

2. **The change:**
   - **`operatorname`** builds the display from the group (Greek commands as their letters, a following `_{…}` as the subscript). The registry gives the engine name. A new display goes in `ParseInfo.names` under its proposed engine name.
   - **Session Enter** asks the engine host to allocate the new displays (G394's `isGiacFree`) before the Giac text is final. A refused display stops the Enter with its words.
   - **A Greek letter with a subscript** is a name, as a Latin one is (`symbol`).
   - **The parser stays pure:** the registry comes in as an option, as `userValues` does.
