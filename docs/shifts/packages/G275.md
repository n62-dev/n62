### gorge, G275: the formula set's model and its checked text form (UI-free), branch `p1/gorge-setmodel`
**Lane:** day, Opus (the shape everything of mh-C3 builds on). **Starts when:** v0.5 work opens, and the owner's yes on mh-C decision 6 (a lazy Symb/Num app sharing R130's step idea, after the pick on `docs/mockups/results-mode.html`).
**Why:** a set re-runs named steps with new numbers. Solve has ten equations and no units (`app/src/apps/solve/`, `slots.svelte.ts:6`), so a set is a new thing with its own checks: unknown names, cycles and repeats must be refused with the name, and a set read from a file or from an AI's text is untrusted. This package has no view, no storage and no evaluation; each comes later (G276, stubs).
**Read:** (line numbers as of de659c02; recheck at start) `app/src/engine/giacPrint.ts:349-421` (`names`, `mapNames`, `namesIn`); `app/src/engine/library.ts:1-60` (how a library is read); `app/src/units/types.ts:19-22` (`UnitSlot`); `docs/mockups/results-mode.html` (the step idea).
**The model:** `FormulaSet = {name, inputs: [{name, value, sigma?, slot?}], steps: [{name, expr, end?}]}`. `value` and `sigma` are decimal text, `slot` and `end` a `UnitSlot`, and `expr` is Giac text over the names of inputs and of other steps (the entry form is the view's business, so no LaTeX here).
1. **First check:** whether `namesIn` returns a multi-letter name as one and excludes a called function (`sqrt(M)`); record it in the report.

   - a valid set: `writeSet(readSet(t))` equals `t`; `readSet` of the output of `writeSet` equals the model.
   - `stepOrder`: `S` uses `M` and is listed first: order `[M, S]`.
   - Each with its error: an unknown name in step `S`: `{error: "unknown", step: "S", name: "Z"}`; `M` uses `S` and `S` uses `M`: `{error: "cycle", steps: ["M", "S"]}`; a repeated name (input or step); a name of a function Giac reads (`sin`) given as an input; a negative `sigma`; a `value` that is not a decimal; a `sigma` that is not a decimal; a step that is not an object; text that is not JSON.
3. **The code:** `readSet(text)` (JSON, every field checked as untrusted), `writeSet(set)`, `stepOrder(set)` in `app/src/sets/model.ts`, in strict TypeScript, using `namesIn`.
