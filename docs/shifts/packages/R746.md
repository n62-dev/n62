### ron, R746: an exact result drawn as a fraction, root, power or matrix goes on the line as editable maths, branch `p1/ron-plainexact`
**Lane:** the freeze's fix lane, Opus (a wrong answer if done badly, see the risk). **The owner's yes:** 2026-11-18 ("commit and push"), before the tag. **Starts when:** –. No lock line changes.

**Why:** the owner, 2026-11-18, on the Fairphone 6: a fraction tapped from history "is treated as one unit: the highlight is in the middle, too small, you cannot edit it, the arrow keys don't work on it". Confirmed by probe (drafts: scratchpad hist-bug, 2026-11-18): two taps on the result 5/6 insert `\res{1}{\frac{5}{6}}` (`App.svelte:204-214` insertResult → `controller.ts:225` → `macros.ts:21`, `captureSelection: true, expand: false`); ◀ jumps from 9 to 0, a typed 7 gives `7\res{1}{\frac{5}{6}}`; the `\htmlStyle` background paints a small box round the fraction bar only. A matrix chip's background covers only its middle band. For an exact result the chip adds nothing: its drawn LaTeX already is its value (the parser turns an exact chip into its exact text).

**The result:**
- An **exact** result (`chip.exact`, no σ, no units) whose shown LaTeX holds a fraction, a root, a power, or a matrix/vector goes on the line as plain LaTeX through the existing "as drawn" branch (`entry.insert(resultToEntry(shown))`, `App.svelte:214`). The caret enters it; ◀/▶ move through it; a digit typed in the denominator edits it.
- Integers, inexact results (rounded digits), σ, ⚠ and unit rows stay chips as today (R147, R63f1, G355).
- **The risk, handled (sandra's sweep, 2026-11-18):** today a digit beside a chip is refused ("put × between a result and a number"). Plain LaTeX loses that, so the insert itself keeps the value one term:
  - after a digit or a closing bracket, or before one, `\cdot` (×) is put between (`2` then 5/6 gives `2\cdot\frac{5}{6}` = 5/3, never drawn as the mixed number 2⅚);
  - a result with a leading minus or a top-level sum goes in brackets (`render/insertable.ts` `hasTopLevelSum` brackets a sum but not a leading minus: add it), so `2` then −5/6 gives `2\cdot\left(-\frac{5}{6}\right)` and −5/6 then x² gives 25/36;
  - the same rule on the too-long fallback (`App.svelte:214`), which has the leading-minus gap today.
