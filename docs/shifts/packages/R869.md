### ron, R869: Help on Find's highlighted row: a function's help sheet, a unit's, prefix's or constant's card from the index, branch `p1/ron-helpfind`
**Lane:** v0.1.1, Opus. **The owner's yes:** 2026-11-22 (point 11; S3: "Help explains the highlight", Find first, then the unit view, R870). **Starts when:** at once. No lock change. The `help` action is read from the layer pressed, so this works whether Help is the key's tap (today) or Shift + the ⚙ key (S2-19).

**Why:**
- In Find, Help is a dead press. `findKey` (`app/src/views/sheetKeys.ts:80,96`) passes only `FIND_PASS`, which holds no `help`, so the press falls to `none` (`:210`, R770). sandra's sweep (`../drafts/2026-11-22-owner-bugs3/s3.md` 11), sofia's rerun (`verify.md` S3-11).
- Content in the index (`app/src/find/_gen/find-index.json`, sofia CONFIRMED):
  - Functions: all 1,149 have a description; the 73 tier-0 functions also have a syntax and an example.
  - Units (452), prefixes (34) and constants (71): no help text at all.
  - What the index does carry: names, `dim`, an exact `si` (`p/q`, with pi where needed, `k+offset` for °C and °F), and for constants `value`, `unc` and `unit` (`find/types.ts:28-45`). Example: `unit:ft` is title "Foot", `dim: m1`, `si: 381/1250` (= 0.3048 exactly).
- Find's preview (`finder.ts:102-112`) shows only "× 381/1250 SI".

**The result:**
- In Find (Math; the unit view's Find; Vars and Memory are the same sheet, `shell.svelte.ts:290-291`), the Help action on the highlighted row opens that item's help as a **level over Find**. ‹, Esc and Back return to Find with its query and highlight as they were.
- **Function or template:** R197's rows (`views/helpSheet.ts` `helpRows`). Its "Insert the example" puts the example at the line's cursor and closes all. A tier-1 function shows `name(…)`, its description, and "not checked".
- **Unit:** title "Help: Foot". The rows, each information only (`keep: true`):
  - Symbol and names: "ft · foot, feet".
  - The quantity: the units menu category whose `dims` hold its `dim` (`spec/units-menu.yaml`, e.g. "Length"); none: left out.
  - The value line "1 ft = 0.3048 m", in the SI unit `siUnit(dim).text` (`units/dims.ts:110`), with the hint "exact".
    - A fraction whose decimal does not end within 30 digits: "= p/q m", then "≈" with 12 digits.
    - pi in `si`: "= π/180 rad ≈ 0.0174532925199 rad", the digits worked out from the index's text.
    - An offset scale: "°C = K − 273.15; a difference of 1 °C is 1 K".
    - No `si`: `unitNote`'s words ("converts only" or "no factor").
  - Tier 1: "not checked".
  - Last, "Insert", which does what Enter on the row in Find does.
- **Prefix:** "k · kilo", "× 1000 = 10³", "exact", Insert.
- **Constant:** "c · speed of light", then the value "299792458 m/s" with "exact (SI definition)" when the index gives no `unc`, else "value ± unc unit" with "CODATA". The index's digits, unrounded. Then Insert.
- No highlighted row (a query that matches nothing), or a row that is no index item (a stored name in Vars or Memory, a category): a dead press.

**Read:** `app/src/views/sheetKeys.ts:75-110,160-235` (`findKey`, `sheetAct`), `views/helpSheet.ts`, `i18n/enHelp.ts`, `find/finder.ts:95-130` (a row's `id` is the item's id), `find/types.ts`, `units/dims.ts:100-130`, `units/slot.ts:81-130` (`exactFactor`), `spec/units-menu.yaml` (categories), `views/sheet.svelte.ts:40-60,400-520` (levels, `back`), `app/test/helpkey.spec.ts`.
