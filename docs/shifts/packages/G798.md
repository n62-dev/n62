### gorge, G798: casback checks laws that need no oracle: matrix scaling and integer signs, branch `p1/gorge-lawcheck`
**Lane:** B, Opus. **Starts when:** G797 (the same matrix generator). A family test (owner-style hunt 2026-11-23: G790, G622, G793, G791 each break a law a machine can check without knowing the answer).
**The bar (owner, 2026-11-23):** v0.1.0's tag waits until no known wrong answer is left in the declared scope (what the keys and Find reach) and these family tests have run green for a week (docs/release-0.1.0.md point 3). This package is one of the four family tests (G797–G800); its `--nightly` mode is what the week counts.
**Why:** Home's own check runs a value twice at two precisions; a fault both runs share (Giac's absolute 1e-12 zero in the matrix code) passes it, so `inv` of a small float matrix showed "14 of 20 digits confirmed" on a wrong matrix. A law between two inputs catches it: scale a matrix by 10^13 and the answer must scale by the known power.
**Read:** `app/scripts/casback.ts`, `tools/probes/casback/check.ts` (its kinds), `tests/golden/casback-known.yaml`, G797's generator.
1. **Tests first:** vitest for each law on a hand case that breaks it on phase-1:
   - **Matrix scaling** (c in 10^−13, 10^−7, 10^7, 10^13; A, B float matrices): `(c·A)·B = c·(A·B)`; `det(c·A) = c^n·det(A)`; `inv(c·A) = inv(A)/c`; `rank(c·A) = rank(A)`; `linsolve(c·A, c·b) = linsolve(A, b)`. Red on phase-1: the product (G790) and `inv` (G622) at c = 10^−13.
   - **Integer signs:** `lcm(±a,±b) = lcm(a,b) ≥ 0` (red: G793), `gcd` the same; `hamdist(a,b) = hamdist(−a−1,−b−1)` for a, b ≥ 0 (red: G791); `a = b·iquo(a,b) + irem(a,b)` for every sign pair.
2. **The change:** a `law` kind in `check.ts`: each law run through Home as the app calls it; a broken law is a failure only when both sides claim their digits (`=` or a confirmed ≈); with ⚠ on either side it passes (an honest mark is not a wrong answer). Compared within the digits both claim. Generated cases from G797's generator and a fixed integer set (small, 2^31 ± 1, 2^63 ± 1, 2^70, negatives). Today's failures go into `casback-known.yaml` with their package ids.
3. **Docs:** casback's header; bug-patterns family 4 names the law check (under "For shared files").
**Done when:** the vitests failed on phase-1's engine where named and pass with the known rows; casback's gate run green; `--nightly` runs; `GOLDEN GATE PASSED`; the core list passes.
