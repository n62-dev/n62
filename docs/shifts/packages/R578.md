### ron, R578: Home draws a matrix result as a grid, as CAS does, branch `p1/ron-homematrixgrid`
**Lane:** A, night-safe, Sonnet (drawing only; the text, copy and marks stay). **Starts when:** after the tag (v0.2's Structure work; the matrix keys and grid are built, R185–R190).

**Why** (F356, found by T4 on 2026-11-16, not the owner; session S11 "A×B, inverse, a linear system"): every matrix *input* on the Home line is drawn 2-D (Shift + 5's grid), but every matrix *result* is one line of brackets. Playwright, Pixel 7, phase-1 e93dec77, A = [[2,1,1],[1,3,2],[1,0,0]] stored, values right against mpmath:

| Input | Home row now | CAS row now |
|---|---|---|
| `A⁻¹` | = [[0,0,1],[−2,1,3],[3,−1,−5]] | a 3×3 grid |
| `A²` | = [[6,5,4],[7,10,7],[2,1,1]] | a grid |
| `A⁻¹ × (1;2;3)` (a column) | = [[3],[9],[−14]] | a column |
| `[[2,1],[1,3]]⁻¹` | = [[0.6,−0.2],[−0.2,0.4]] | the grid with 3/5, −1/5, −1/5, 2/5 |

A column result as `[[3],[9],[−14]]` is the worst case: the solution vector of a linear system, the commonest matrix result, reads as nested lists. Its value and marks are right; only the drawing differs from the input's and from CAS's.

**Cause:** Home draws its result from the display text alone (`homeResultToLatex`, `app/src/render/home.ts:86-96`, through `app/src/state/displayMode.ts:227`), and Giac's matrix print is `[[…],[…]]`. The row already knows its shape and elements (`FactsSource.shape`, `items`, `app/src/state/results.ts:31-38`), each element with its own facts (the grid's ≈ and ⚠, R188 fix round 1).

**Read:** `app/src/render/home.ts`; `app/src/state/displayMode.ts:180-230`; `app/src/state/results.ts:20-60`; `app/src/views/matrixGrid.svelte.ts` (how the grid draws one element, `formatConfirmed`, `:327`); the CAS view's matrix drawing (`app/src/engine/giacPrint.ts`, G173); `app/test/matrix*.spec.ts`.
