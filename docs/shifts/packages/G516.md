### gorge, G516: a backup's definitions and chips pass the library's check before they are stored, branch `p1/gorge-backupcheck`
**Lane:** B, night-safe, Opus (Giac text replayed at every start; a wrong refusal loses a user's restore). **Starts when:** after the v0.1.0 tag (0.3); after G394 (the registry's `names` part joins the backup), R363 and R364 (both edit `backupSync.ts`) if they are open.

**Why:** (arch review 2026-11-10, B4, draft X20; rechecked at `5a583f31`)
- **Two doors, two locks.** A library file goes through Giac's parse tree and is refused when a command changes state or evaluates a string (`app/src/engine/library.ts:79-87` `changes`, over `stateHeads`, `app/src/engine/stores.ts:55`, `:100`, `:147-149`). A backup's `defs` are checked for shape only (`app/src/state/backup.ts:226` → `validDefs`, `app/src/engine/defs.ts:116-147`), and every `cmds` string is replayed as Giac text at each start.
- **A third door since the sync folder:** another device's backup in the shared folder goes through the same `checkBackup` (`app/src/sync/backupSync.ts:164`) and, in silent mode, is applied with no question (`:168-171`). A damaged or crafted file in a synced folder reaches the replay without a tap.
- **Chips:** a chip value goes to Giac in brackets unless it holds `;` or `:=` (`app/src/input/chip-giac.ts:34`); chips come from the backup's history and user keys (`validChips`, `app/src/input/chips.ts:71`). `purge(A)` as a chip value passes.
- **The replay has no time limit of its own** (the watchdog arms only for Home and unit calls, `app/src/engine/workerEngine.ts:374-383`): a replay that never returns ends by G19's two failed starts and the safe start. That stays as is; this package's check parses (`giac_parse`, bridge-2) and never evaluates, so it can neither hang on a value nor change state.
- **Bounded harm:** Giac in wasm reaches no file and no network; a bad file can purge or redefine names or hang starts. Principle 3: a stored value never changes behind the user's back.
