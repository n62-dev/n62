### ron, R357: the name field takes any defined name (Store sheet, and a typed row in Vars), branch `p1/ron-namefield`
**Lane:** A, Opus (sheets and keys); the owner tries ΔT on the phone after the merge. **Starts when:** R356 and R353 merged; after the v0.1.0 tag (0.2), before R346.

**Why:**
- **The rule** ([the design note](../../research/name-rules.md) section 1): a defined name is any composite. It starts with a Latin or Greek letter; then come letters, Greek letters and digits, and one optional subscript at the end. It is entered as one token.
- **The Store sheet takes only Latin letters and digits** (`app/src/views/sheetKeys.ts:105-115`). Shift+9 is a "line" key there: it closes the sheet and opens the palette on the line (`app/src/keyboard/route.ts:325-331`). So no stored name can hold a Greek letter.
- **Vars inserts only stored names.** A free ΔT for a CAS formula or the unit view's letters (R346) has no way onto the line.
- **R357 used to allow a Greek letter only in first place.** The registry (G393) removes that limit.
