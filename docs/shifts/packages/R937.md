**The result: one rule, one helper, every path.** A pick (input or result, by Enter, a second tap or a key that takes what is lit) or a Paste that lands on a line with text goes in as **one term**:
- **(a) Brackets** around it unless it is one plain term (a number, a name, a chip, a single atom: `isPlainTerm`, `field.ts:87`) or it is alone in its box. "Alone in its box": after the selection is removed, nothing else stands at the caret's depth in that box (the box start is the empty sentinel; read from `getElementInfo` depth and latex, as `asOneTerm` does). An empty line, an empty argument, exponent, denominator or ⁿ√ index count; one-line mode has no boxes, so there only the empty line counts.
- **(b) A ×** between it and a neighbour that ends or starts a term: a digit, a point, a closing bracket, `!`, `%`, a chip, a name (a letter or a user function name: `f` + `x+1` is `f×(x+1)`, never a call), π or a constant, a fraction, a root.
- **(c) After ᴇ** the pick goes in bare (`1.5ᴇ` + `−3` is `1.5ᴇ−3`; a non-integer pick there is refused as typing it is).
- **(d) A pick that stores** (`value ▶ name`) onto a line with text inserts the value part only; on an empty line it keeps `▶ name` as today.
- **(e) A result chip** onto a line with text gets the same × in place of the refusal; the refusal in `parse.ts` stays the net for digits typed next to a chip.
