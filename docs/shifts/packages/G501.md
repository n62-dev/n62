### gorge, G501: Polynomial roots with units: each root in the unknown's unit, branch `p1/gorge-polyunits`
**Lane:** B, night-safe, Sonnet (the same transform as G500 on one more request kind; the roots' check is today's). **Starts when:** R521 merged; after the v0.1.0 tag (0.2). S45's rsu-4.

**Why:**
- **S45's cut** ([the note](../../research/r-solveunits.md) section 7, rsu-4): "the same transform for `kind: "poly"`; each root in the unknown's unit". After R521 a Solve with units goes through G500's `solveJob`, but Polynomial roots does not: `polyRoots` sends `{ kind: "poly", equation, unknown, knowns }` with the raw equation and plain knowns (`app/src/apps/solve/app.svelte.ts:386-415`).
- **What breaks without it:** E1 `X^2=A` with A = `4 m²` on its Num row. Solve gives X = 2 m (R521). Polynomial roots sends A unit-blind: R521 keeps R502's "come with the next step" line for it until this package.
- **The roots' check is unit-free already:** `proot` and the substitute-back run on the plain polynomial (`app/src/engine/solve.ts:189`, `SolveRequest` `kind: "poly"`, `engine/types.ts:218`). In the typed units the floor of 1 keeps its meaning, as for solve1 (S45 section 4).
