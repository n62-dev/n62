### gorge, G518: the worst case min…max of a unit-view result over its typed ±, exact, for monotone formulas only, branch `p1/gorge-worstcase`
**Lane:** B, night-safe, Opus (a range shown beside σ: an interval that misses the true worst case is a silent wrong answer). **Starts when:** G508 merged (its max/min rewrite); after the v0.1.0 tag (0.3). R519 draws it.

**Why:**
- **The owner's list** (night review 2026-11-09, fh-3, `docs/archive/night-review-2026-11-09.md:73`; carried 11-14 and 11-16): "no worst-case min…max for a ± chain". docs/03 section 7 item 3: "worst-case … tolerance analysis would be a later add-on". A tolerance stack-up needs the limits, not σ.
- **Today only σ exists** (G18, G41): `pasupm(12.34,0.05)*{m}*pasupm(3.2,0.1)*{m}` gives `39.5 ± 1.2` m² and nothing else (`tools/probes/unit-result.ts` at `5a583f31`). Its worst case over the typed ± is 38.099 … 40.887 m² (12.29·3.1 and 12.39·3.3, derived).
- **Narrow and exact, by design:**
  - The range is the natural interval extension of the formula, computed exactly in Giac. Each input is its value ± its typed u, a constant with σ its value ± u.
  - Moore's theorem: for a formula in which **every input appears once** and every operation is continuous and monotone on each argument's range, that interval is exactly the range: no overestimate, no miss.
  - So the package computes it only there, and says why not everywhere else.

**Allowed (monotone on the range, else refused with the reason):**
- `+ − × ÷` (a divisor's range through 0 is refused);
- integer powers (an even power whose base spans 0 starts at 0), `sqrt` and rational powers on a range ≥ 0;
- `exp`, `ln`, `log10` (range > 0), `abs`;
- `sinh`, `tanh`, `asinh`, `atan`;
- `max`, `min` (G508);
- a slot's or constant's factor.

**Refused, with words:** a result chip after ± or as a value (its σ is no range; G523 carries the chain's range); `sin`, `cos`, `tan`, `cosh`, the other inverses, step functions and `pasmod`, integrals, piecewise, user functions; an input used twice; an absolute temperature or level end slot.
