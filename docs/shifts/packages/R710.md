**Why:**
- **F385 (T5, [findings.md](../../research/t5-ui/findings.md)):** in N62 · Dark, the default on Android, the Function app's Plot draws its axes, its tick numbers and the trace dot in black on rgb(9, 39, 38). The contrast is about 1.3 : 1; the intended `--muted` (#abccca) gives about 9 : 1. Read from the canvas's own pixels on the emulator.
- **The cause:** `app/src/apps/function/FunctionPlot.svelte:81-82` and `:112` pass `"var(--muted)"`, `"var(--line)"` and `"var(--text)"` to JSXGraph's canvas renderer (`:75`). A canvas cannot resolve CSS custom properties, so those strokes stay black. The curves are right: `curveColors()` gives literal colours (`app.svelte.ts:29`).
- **The rule:** docs/05 3.7 (contrast at least 4.5 : 1 for text, in every theme); the tick numbers are text.
