**Cause:**
- An empty template box is MathLive's `\placeholder{}`; an operator where a value belongs is `\times`. Both reach `atom()`'s default branch, which names the LaTeX command (`app/src/input/parse.ts:809-810`, `parse.unsupportedCommand`, `app/src/i18n/enParser.ts:47`).
- `atom()` at the end of the line calls `this.fail("parse.unexpectedEndOf")` (`parse.ts:443`), and `fail` wraps every message in `parse.atEnd` = "{msg} at end of input" (`parse.ts:54-56`, `enParser.ts:91`): the phrase twice.
