**Why:**
- **HUNT.md H3 (arch review 2026-11-10), still red at `5a583f31`** (`FACTS=1 MODE=cas node tools/probes/engine.ts …` and Home):
  - CAS `evalf(int(exp(-x^2),x,0,1))` → `0.746824132812`, facts `reliableDigits: 13, warn: "unaudited", why: { unaudited: ["int"] }`: **⚠**;
  - Home `int(exp(-x^2),x,0,1)` → `0.746824132812`, exact `1/2*sqrt(pi)*erf(1)`, `reliableDigits: 38`: **≈**;
  - the same for CAS `evalf(sum(1/k^2,k,1,inf))` (⚠, `unaudited: ["sum"]`) and `evalf(int(ln(x),x,1,2))` (⚠, `unaudited: ["int"]`).

- **Cause** (read at `5a583f31`; step 1 confirms): CAS's output of `evalf(…)` is a float, so its facts come from `floatFacts` re-running the *input* (`app/src/engine/host.ts:1184`), whose `int` and `sum` are unaudited calls: `warn: "unaudited"`, and `whyOf(facts, exactInput)` (`:1191`) names them. Inside CAS's `evalf`, Giac computes `erf` itself, so relabelling CAS's own value would not be the same check.
