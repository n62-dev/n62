### ron, R822: in the Store sheet a plain tap types its letter in the case Alpha types in the view (CAS: `a`), branch `p1/ron-storecase`
**Lane:** v0.1.1, Sonnet. **Starts when:** after R820 (its `sheetFace` reads `storeKey`, so the faces follow this change with no edit of their own) and **the owner's answer to the rule** (below; the docs do not settle it). No lock change: the store sheet's keys are not in `spec/layout-lock.yaml`.

**Why** (a vitest probe of `storeKey` on phase-1 b8a2af27, `views/sheetKeys.ts:105-114`):

| key | Home tap | Home Alpha | Home Shift+Alpha | CAS tap | CAS Alpha | CAS Shift+Alpha |
|---|---|---|---|---|---|---|
| Vars | A | A | a | **A** | a | A |
| sin | G | G | g | **G** | g | G |
| x | x | D | d | x | d | D |

- In CAS the tap and Alpha + the same key store two different names. The tap falls through to `sheetKey` → `letterOf` (`:113`, `:44-47`), the spec's capital, while Alpha goes through `actionFor` with R58's swap (`keyboard/keyboard.ts:361-375`).
- **What the user meets:** in CAS, 7 ▶ then a tap on Vars stores `A`; on the line Alpha + Vars types `a` (R58), a different, empty name, so `a` comes back as a symbol, not 7. Both names are valid in CAS (`docs/archive/store-design.md:16`: a–z and A–Z store and read back, 52/52).
- **The docs:** docs/05:51 "a key that types a letter on the line types it into the name (x, Alpha + a key, …)": this covers Alpha, not the plain tap. The `storeKey` comment (`:101`) "a plain key that types no letter types its Alpha letter, as in every sheet" does not say which case. docs/06:49 (R58): the G2's CAS types lower case on Alpha; a lower-case CAS name costs 1 press, not 3. Vars, Find and Memory type lower case on purpose (docs/04:216; their filter matches either case).

**The rule (recommended; the owner's question):** in the Store sheet a plain tap on a letter key types what Alpha + that key types in this view: `A` in Home, `a` in CAS. The name stored is then the name the same key types on the line. Home is unchanged. The A–Z grid stays as it is (a tap on a cell stores that capital).
