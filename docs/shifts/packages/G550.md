### gorge, G550: a Home row whose σ input cannot be carried says so, never 12 bare digits, branch `p1/gorge-sigmalost`
**Lane:** B, night-safe, Opus (a mark that lies; pinned by tests with the real engine). **Starts when:** –. Before the freeze if a lane has room: it completes G355's and G371's σ in v0.1.0; else a fix row before the tag (release-0.1.0.md line 35).
**Why:** (T2 bug hunt 2026-11-16, F301; probes in `../drafts/2026-11-16-ultra/t2-bughunt/probes/names.mts`, engine `_out/gsl`, phase-1 `e93dec77`.) A Home value that rests on a σ input (an inexact constant such as G, a σ chip (G355) or a stored name with σ (G371)) loses its σ without a word on four paths:
- **Gamma, factorial, `!`:** `W:=G·5.972ᴇ24·70/6371000²` (σ 0.0154), then `W!` shows `3.76939487348E1653` ≈, no σ. Right: σ = 3.80ᴇ1652, 10.1 % (mpmath `diff(gamma(t+1))`, dps 30). `factorial(G·1ᴇ11)` shows `2632.87776703` ≈, no σ; right σ 0.7785. Cause: σ is `evalf(…,20)` of `diff` (`app/src/engine/constUnc.ts:186-191`); `diff(Gamma(x))` is `Psi(x)·Gamma(x)`, and Giac leaves `Psi` of a multiprecision float unevaluated (`evalf(Psi(76743/10000),20)` → `Psi(7.6743000000000000000)`; at double precision it gives 1.97131199508, mpmath 1.97131199508361). `decimalFromString` then fails and `constUncDigits` returns undefined.
- **No derivative:** `max(W,1)`, `min(W,1000)`: `diff(max(x,1),x)` stays unevaluated.
- **A user function:** `f(t):=W·t`, `f(2)` shows `1374.79627967` ≈, no σ, while `W·2` has σ 0.0309. The σ body is the input text (`nameSigma`, `app/src/engine/nameSigma.ts:52-56`), which holds no W, so ∂/∂W is 0 and σ zero means "no σ".
- **Not one real number:** `W·[1,2]`, `sqrt(W-700)` (complex) drop σ by design (`constUnc.ts:178`).
- In every case `host.ts:899` (`if (n === undefined) return out;`) returns the row as if no σ input had gone in: 12 digits, no σ line, no muting. The unit view refuses the same Gamma input ("could not evaluate"), so the two views disagree (family 8).
