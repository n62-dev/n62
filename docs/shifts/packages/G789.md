### gorge, G789: median and the quartiles refuse undef and a free name in a list, and sort ±inf by value, branch `p1/gorge-medianundef`
**Lane:** B, Opus. **The owner's yes:** 2026-11-23 (sofia's email 8 check found it; the owner chose "refuse" for a free name, which is the same as the matrix form). **Starts when:** at once. A wrong answer.
**Why:** G786f1 (patch 0058) refuses a complex element, but only on the numeric path. A list that is not fully numeric takes Giac's other path (`islesscomplexthanf_sort` in misc.cc `_median` and its siblings, before `ascsort`), and that path sorts undef, a name and ±inf by form, not by value. A probe on `engine/giac/_out/gsl` at 5c518933 (`node engine/giac/smoke.mjs`):
- `median([3,1,undef])` = 3 and `median([3.0,1.0,undef])` = 1.0: the same data gives two answers. `median([1,2,undef,undef])` = 2. `quartile1([1,2,3,undef,5])` = 2. `quantile([1,2,undef,4],0.5)` = 2. `quartiles([1,2,3,undef,5,6])` = [1,2,3,6,undef].
- `median([[1,undef],[3,2],[2,8]])` = [2.0,2.0]: a column that holds undef still gives a number.
- `median([3,1,x])` = 3, which is wrong for most x (for x = 0 the median is 1). G786f1 already refuses a name in a matrix.
- -inf is sorted last: `median([3,1,-inf])` = 3 (should be 1); `median([3,1,inf,-inf,2])` = 3 (2); `quantile([1,-inf,3],0.5)` = 3 (1); `quartiles([1,2,3,-inf,5,6])` = [1,2,3,6,-infinity] (the minimum is -inf). `median([3,1,inf])` = 3 is right only by chance.
- `median([3,1,0.0/0.0])` is already an error ("Unable to transpose"). Keep that as a control.
