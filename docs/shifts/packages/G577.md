### gorge, G577: 20 °C + 5 K says what to do (and, on the owner's yes, gives 25 °C), branch `p1/gorge-tempplusdiff`
**Lane:** B, night-safe, Opus (units). **Starts when:** G385 merged (same function, `jobOf`). Part 2 only on the owner's yes (T4's SUMMARY.md, "Needs the owner").

**Why** (F354, found by T4 on 2026-11-16, not the owner; session S09 "temperatures", "sums that should be refused"): an inlet temperature plus a rise is everyday heat work. In the unit view (Playwright, Pixel 7, phase-1 e93dec77), `20 [°C] + 5 [K] → □` Enter is refused with **"Use K or Δ°C for a temperature difference"** (screenshot in T4's notes). The difference *is* in K, so the message asks for what was typed and leaves the user with no way forward. The refusal itself is decided (decisions.md G17: "other temperature mixes are refused"), the message is not: it is the one text for every `temperature` refusal (`app/src/units/messages.ts:17-18`, `app/src/i18n/enUnits.ts:11`), thrown here by `jobOf`'s "an absolute temperature … allowed only alone" rule (`app/src/units/build.ts:589-610`, `refuseSpecial` at :610).

**Right value (derived):** an absolute temperature plus an interval is an absolute temperature: 20 °C + 5 K = 25 °C = 298.15 K (1 K of interval = 1 °C of interval, SI Brochure 2.3.1, the definition of the degree Celsius).
