- `5` Enter. Tap the input: it lights. Tap it again: the line is `5`. Tap the input twice again: the line stays `5` and the pick drops. Taps on another row's input in between do not change this.

- So since R832 the second tap and Enter disagree, although R273 (night review 2026-11-09, item 11) asked for "Enter and the second tap alike". The owner's first insert worked only because the line was empty.
